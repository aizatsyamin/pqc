The error "Requested unknown parameter 'displayIndex' for row 0, column 0" occurs because in your tableSBOMNew config (lines 527–534), you still have:
dataSrc: "",

and then column 0 expects "data": "displayIndex". Because the backend API /newreport/getSBOMReport does not have a property named displayIndex in its raw JSON, DataTables warns that it cannot find that field.
Also, you have leftover preDrawCallback logic using sbomMap. You should remove that mixed approach and let dataSrc attach displayIndex right when data arrives.
The Fix
Update lines 527–535 in tableSBOMNew so that dataSrc is a function that calculates displayIndex on each row before passing the data to the columns:
const tableSBOMNew = new DataTable('#tableSBOMNew', {
    ajax: {
        url: "/newreport/getSBOMReport",
        dataType: "json",
        dataSrc: function (json) {
            var list = Array.isArray(json) ? json : (json.data || []);
            
            // Sort by category first, then by IDs so groupings match Inventory
            list = sortDataset(list);

            var assetCounter = 0;
            var lastAssetId = null;
            var compCounter = 0;

            for (var i = 0; i < list.length; i++) {
                var item = list[i];

                // When asset changes, increment major number (1, 2, 3...)
                if (item.assetId !== lastAssetId) {
                    assetCounter++;
                    lastAssetId = item.assetId;
                    compCounter = 0; // Reset component counter
                }

                compCounter++;
                // Creates "1.1", "1.2", "2.1", etc.
                item.displayIndex = assetCounter + "." + compCounter;
            }

            return list;
        }
    },
    columns: [
        {
            data: "displayIndex",
            defaultContent: ""
        },
        // ... rest of your columns remain as they are

Steps to finalize:
 * Replace dataSrc: "" on line 529 with the dataSrc: function (json) above.
 * Add defaultContent: "" inside { data: "displayIndex" } on line 534 as a fallback safety guard so DataTables never triggers a popup alert.
 * Delete the old preDrawCallback: function (settings) { ... } block (lines 682–699) so it doesn't conflict.
